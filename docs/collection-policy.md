# 수집 정책 및 채널별 허용 여부

> 다른 학생도 같은 기준으로 판단할 수 있도록 채널마다 확인 결과와 확인 날짜를 기록합니다.
> 계획서와 달라진 점의 배경은 [`decisions.md`](decisions.md)에 있습니다.

## 원칙

1. 홈페이지는 `robots.txt`와 이용약관을 **모두** 확인하고, 허용된 범위에서만 수집한다.
2. 대전대학교 홈페이지(사업단 홈페이지 포함)는 공지 목록·본문 자동 수집을 제한하므로, 허용된 사업단·학과 **메인 페이지의 최신 공지 칸**에서 제목·날짜·링크만 가져온다.
3. 공지 목록·본문은 **자동으로 수집하지 않는다.** 학교에 허가 절차를 문의했고, 보안상 어렵다는 회신을 받았다(아래 기록).
4. 본문 속 마감일은 사용자가 직접 연 공지를 **크롬 확장 프로그램**으로 정리하거나, 링크·본문·캡처를 AI에 넣는 **프롬프트 방식**으로 얻는다.
5. 인스타그램은 이번 활동 기간에 자동 수집하지 않고 **프롬프트 방식**으로 처리한다.
6. 모든 자동 수집은 **하루 1회**로 제한한다.
7. 게시물 속 개인정보는 저장하지 않으며, 원문 전체가 아닌 **정리한 정보와 원문 링크만** 보관한다.

## 입력 경로별 정리

| 경로 | 누가 여나 | 읽는 범위 | 자동 여부 |
|---|---|---|---|
| 메인 공지 칸 수집 | 프로그램 (하루 1회) | 허용된 메인 페이지의 최신 공지 칸: 제목·날짜·링크 | 자동 |
| 크롬 확장 프로그램 | 사용자 | 사용자가 연 탭 하나: 제목·본문·주소 (+ 포스터면 화면 캡처) | 사용자가 버튼을 누를 때만 |
| 프롬프트 방식 | 사용자 | 사용자가 AI에 붙여넣은 내용 | 사용자가 직접 |

## 크롬 확장 프로그램 사용 원칙

- 권한은 `activeTab`(버튼을 누른 탭에만 접근), `scripting`, `storage`만 쓴다. 모든 사이트에 자동으로 붙는 콘텐츠 스크립트는 쓰지 않는다.
- 공지 목록을 돌며 글을 자동으로 열거나, 사용자 몰래 다른 페이지를 불러오는 기능은 만들지 않는다.
- 읽은 본문은 AI 정리에만 쓰고 저장하지 않는다. 저장하는 것은 정리된 항목과 원문 링크뿐이다.
- 포스터는 사용자가 연 페이지에 **이미 불러와 화면에 보이는 이미지**를 그대로 쓴다. 이미지를 새로 내려받지 않는다.
- AI 결과는 사용자가 원문과 대조해 **직접 확인·수정한 뒤** 저장한다.
- API 키는 사용자가 확장 설정 화면에 직접 넣고, 사용자의 브라우저에만 저장한다.

### 이 방식이 자동 수집이 아니라고 보는 근거 (2026-11-28 정리)

| 기준 | 자동 수집(크롤러) | 마감이 크롬 확장 |
|---|---|---|
| 누가 페이지를 여나 | 프로그램 | 사용자 |
| 언제 읽나 | 정해진 시간마다 | 사용자가 버튼을 누를 때 한 번 |
| 몇 개를 읽나 | 목록 전체 | 지금 열린 탭 하나 |
| 학교 서버에 추가 요청 | 있음 | 없음 (이미 받은 화면을 읽음) |
| 원문 저장 | 흔함 | 없음 (정리한 항목과 링크만) |

사람이 공지를 읽고 일정을 메모하는 것과 같은 범위로 설계했다.
- **남은 확인 사항**: 담당 교수님 11/10 회신에서 "사용자가 연 공지를 버튼으로 등록하는 방식도 학교 이용 기준에서 허용되는지 별도 확인 필요"라고 했다. 확인 결과가 나오면 이 문서에 기록한다.

## 확인 방법

- `robots.txt`: 사이트 주소 뒤에 `/robots.txt`를 붙여 열어 본다. 예: `https://example.ac.kr/robots.txt`
  - `Disallow: /` → 전체 수집 금지
  - `Disallow: /board/` → 해당 경로 수집 금지
  - 파일이 없으면 이용약관을 기준으로 판단한다.
- 이용약관: 사이트 하단의 이용약관·저작권 정책에서 자동 수집(크롤링) 관련 조항을 확인한다.

### 참고: `www.dju.ac.kr` robots.txt 주요 제한 (2026-10-22 확인, 2026-11-10 재확인)

| 경로 | 의미 |
|---|---|
| `/*/na/ntt/` | 모든 게시판 목록·본문 (사업단 게시판 포함) |
| `/*/cm/cntnts/` | 일반 콘텐츠 페이지 |
| `/*/cp/cttpc/` | 콘텐츠 페이지 |
| `/*/depart/` | 학과 페이지 |
| 이미지·문서 파일 | `.jpg` `.png` `.pdf` `.hwp` 등 |

사업단 홈페이지(`/sw/` 등)도 모두 `www.dju.ac.kr` 아래에 있어 같은 규칙이 적용된다.
