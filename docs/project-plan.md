# 프로젝트 계획서

> 사업단에 제출한 활동계획서(2026.10.05)를 요약한 문서입니다.

## 1. 과제 개요

- 과제명: 마감이 — 나만의 자동화 비교과 캘린더
- 분야: AI 활용 프로젝트
- 수행 기간: 2026.10.12 ~ 2026.11.30 (최종발표 2026.12.03)
- 팀: 크로노스 (박세훈, 이혜령, 윤재원)

## 2. 목표

- **최종 목표**: 대전대학교 학생 누구나 이 레포를 보고 자기만의 비교과 캘린더 자동화를 만들 수 있게 한다.
- **핵심 기능**: 공지 매일 자동 수집 → AI 판별·정리 → 공지 체크 화면 → 체크한 공지만 구글 캘린더 등록 → 새 공지 알림
- **세부 목표**
  - 활동 기간 내 대전대학교 공식 인스타그램과 사업단 채널 대상 자동화 완성
  - 실제 공지 30건 기준 마감일 정리 정확도 90% 이상
  - 팀 외부 학생 5명이 레포 안내만으로 자기 캘린더 자동화 구현

## 3. 역할 분담

| 이름 | 역할 | 담당 업무 |
|---|---|---|
| 박세훈 | 팀장 | 일정·레포 관리, 공지 정리 프롬프트, 학교 수집 허가 요청, 인스타그램 공식 API 연동, 매일 자동 실행, 결과 발표 |
| 이혜령 | 팀원 | 홈페이지 메인 페이지 수집, 공지 체크 화면, 구글 캘린더 등록 |
| 윤재원 | 팀원 | 정답 자료 작성, 정확도 평가, 따라하기 안내서·에이전트용 안내 파일, 팀 외부 학생 설치 평가 |

## 4. 일정

| 단계 | 기간 | 계획 | 산출물 |
|---|---|---|---|
| 1단계 | 10.12 ~ 10.24 | 채널 목록 정리, 수집 가능 여부 확인, 학교 수집 허가 요청, 인스타그램 공식 API 준비, 정답 자료 작성 | `config/channels.yaml`, `docs/collection-policy.md`, `data/ground_truth/` |
| 2단계 | 10.25 ~ 11.06 | 인스타그램·홈페이지 메인 수집 기능, AI 정리 기능, 프롬프트 방식 먼저 공개 | 수집기, AI 정리 모듈, `prompts/` |
| 3단계 | 11.07 ~ 11.18 | 공지 체크 화면, 구글 캘린더 등록, 매일 자동 실행, 새 공지 알림 | Streamlit 화면, GitHub Actions |
| 4단계 | 11.19 ~ 11.30, 12.03 | 정확도 평가, 팀 외부 학생 설치 평가, 안내서·에이전트용 안내 파일 보완, 결과 발표 | 평가 결과, 결과보고서, 발표자료 |
