# app

## 공지 체크 화면 (`streamlit_app.py`)

공지 목록을 원문 링크와 함께 보여 주고, 캘린더에 넣을 공지를 체크하는 화면입니다.

```bash
pip install -r requirements.txt
pip install -e .
streamlit run app/streamlit_app.py
```

브라우저에 화면이 열립니다. (자동으로 안 열리면 터미널에 나온 `http://localhost:8501` 주소를 엽니다.)

### 왼쪽 메뉴

- **공지 목록**
  - `GitHub 자동 수집 (data 브랜치)`: 매일 자동 실행([`docs/daily-automation.md`](../docs/daily-automation.md))이 저장한 `notices.json`. fork한 레포라면 주소의 `DJU-Chronos/MAGAMI`를 내 레포로 바꿉니다. 10분 동안은 같은 결과를 보여 주므로, 바로 다시 받으려면 `새로 가져오기`를 누릅니다.
  - `내 컴퓨터 파일`: 기본은 `data/notices.json` (`python -m magami.daily`로 만든 파일)
- **크롬 확장 JSON**: 확장에서 저장한 JSON을 여러 개 올릴 수 있습니다. 공지 1건 파일과 여러 건을 모은 파일 모두 됩니다. 같은 공지(id)가 목록에 있으면 **올린 쪽의 마감일**이 쓰이고, 비어 있는 칸만 목록에서 채웁니다.
- **보기**: `마감일 있는 공지만`, `마감 지난 공지 숨기기` (한국 시간 기준, 마감일이 오늘인 공지는 보임)

### 화면

- 위쪽 숫자: 공지 수 / 마감일 확인됨 / 마감일 미확인 (필터와 상관없이 전체)
- 표: 등록(체크) · 마감일 · 시각 · 제목 · 채널 · 게시일 · 원문(링크)
  - 마감이 가까운 순서, 마감일 미확인 공지는 아래쪽에 최근 게시일 순서
  - 공지가 아니라고 정리된 글(`is_notice: false`)은 보이지 않습니다.
  - 필터를 바꿔도 체크한 공지는 그대로 남습니다.
- 마감일은 AI가 정리한 값이라 틀릴 수 있습니다. **캘린더에 넣기 전에 원문과 꼭 대조하세요.**

마감일이 `미확인`인 공지는 `원문`의 `열기`로 공지를 열고, 크롬 확장으로 정리해 JSON을 저장한 뒤 이 화면에 올립니다.

### 올린 JSON 저장하기

JSON을 올리면 `💾 data/notices.json에 합쳐 저장` 버튼이 나옵니다. (`내 컴퓨터 파일`을 고른 경우에는 그 파일에 저장)

- 지금 목록(올린 JSON 포함)을 파일에 **합칩니다**. 파일에 있던 공지는 지우지 않습니다.
- 같은 공지는 화면 쪽 값이 쓰이고, 비어 있는 칸만 파일 쪽에서 채웁니다.
- 다음부터는 `내 컴퓨터 파일`로 열면 JSON을 다시 올리지 않아도 됩니다.
- `data/notices.json`은 각자 컴퓨터용 파일이라 `.gitignore`에 등록되어 있습니다. (매일 자동 수집 결과는 `data` 브랜치에 따로 저장됨)

### 구글 캘린더 등록

표에서 공지를 체크하고 `📅 체크한 N건 구글 캘린더에 등록`을 누르면 **내 구글 캘린더**에 일정이 들어갑니다.

- 일정 제목은 `[마감] 공지 제목`, 설명에 신청 기간·대상·신청 방법·원문 링크가 들어갑니다.
- 마감 시각이 있으면 그 시각까지 30분짜리 일정, 없으면 마감일 하루 종일 일정입니다. 하루 전에 알림이 옵니다.
- 마감일이 `미확인`인 공지는 경고만 보여 주고 건너뜁니다.
- 같은 공지를 다시 누르면 `이미 등록됨`으로 나오고 일정이 두 번 생기지 않습니다.
- 필터로 숨긴 공지도 체크해 두었다면 함께 등록됩니다. (버튼의 N건에 포함)

#### 처음 한 번: 구글 로그인 준비 (`credentials.json`)

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만들고, **API 및 서비스 → 라이브러리**에서 **Google Calendar API**를 사용 설정합니다.
2. **OAuth 동의 화면**을 만듭니다. 사용자 유형은 **외부**, 테스트 사용자에 **내 Gmail 주소**를 추가합니다.
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID** → 애플리케이션 유형 **데스크톱 앱** → 만들기 → JSON 다운로드
4. 받은 파일 이름을 `credentials.json`으로 바꿔 **레포 최상위 폴더**(README.md가 있는 곳)에 넣습니다.
5. 처음 등록 버튼을 누르면 브라우저에 구글 로그인 창이 열립니다. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르고 캘린더 일정 권한을 허용합니다. (내가 만든 테스트용 앱이라 나오는 화면입니다.) 로그인하면 `token.json`이 생기고, 다음부터는 바로 등록됩니다.

- 권한은 **일정 만들기·찾기**(`calendar.events`)만 요청합니다.
- `credentials.json`과 `token.json`은 `.gitignore`에 등록되어 있습니다. **절대 커밋하거나 다른 사람에게 보내지 마세요.**
- 기본 캘린더가 아닌 다른 캘린더에 넣으려면 `.env`에 `GOOGLE_CALENDAR_ID=캘린더ID`를 적습니다. (구글 캘린더 → 캘린더 설정 → 캘린더 통합 → 캘린더 ID)
