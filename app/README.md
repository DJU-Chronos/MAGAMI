# app

## 공지 체크 화면 (`streamlit_app.py`)

공지 목록을 원문 링크와 함께 보여 주고, 캘린더에 넣을 공지를 체크하는 화면입니다.

```bash
pip install -r requirements.txt
pip install -e .
streamlit run app/streamlit_app.py
```

브라우저에 화면이 열립니다. (자동으로 안 열리면 터미널에 나온 `http://localhost:8501` 주소를 엽니다.)

### 왼쪽 메뉴

- **공지 목록**
  - `GitHub 자동 수집 (data 브랜치)`: 매일 자동 실행([`docs/daily-automation.md`](../docs/daily-automation.md))이 저장한 `notices.json`. fork한 레포라면 주소의 `DJU-Chronos/MAGAMI`를 내 레포로 바꿉니다. 10분 동안은 같은 결과를 보여 주므로, 바로 다시 받으려면 `새로 가져오기`를 누릅니다.
  - `내 컴퓨터 파일`: 기본은 `data/notices.json` (`python -m magami.daily`로 만든 파일)
- **크롬 확장 JSON**: 확장에서 저장한 JSON을 여러 개 올릴 수 있습니다. 공지 1건 파일과 여러 건을 모은 파일 모두 됩니다. 같은 공지(id)가 목록에 있으면 **올린 쪽의 마감일**이 쓰이고, 비어 있는 칸만 목록에서 채웁니다.
- **보기**: `마감일 있는 공지만`, `마감 지난 공지 숨기기` (한국 시간 기준, 마감일이 오늘인 공지는 보임)

### 화면

- 위쪽 숫자: 공지 수 / 마감일 확인됨 / 마감일 미확인 (필터와 상관없이 전체)
- 표: 등록(체크) · 마감일 · 시각 · 제목 · 채널 · 게시일 · 원문(링크)
  - 마감이 가까운 순서, 마감일 미확인 공지는 아래쪽에 최근 게시일 순서
  - 공지가 아니라고 정리된 글(`is_notice: false`)은 보이지 않습니다.
  - 필터를 바꿔도 체크한 공지는 그대로 남습니다.
- 마감일은 AI가 정리한 값이라 틀릴 수 있습니다. **캘린더에 넣기 전에 원문과 꼭 대조하세요.**

마감일이 `미확인`인 공지는 `원문`의 `열기`로 공지를 열고, 크롬 확장으로 정리해 JSON을 저장한 뒤 이 화면에 올립니다.
