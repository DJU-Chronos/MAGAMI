> 흩어진 비교과·공모전 공지를 매일 모아 AI로 정리하고, 원하는 공지만 구글 캘린더에 등록하는 자동화 도구

## 2. 문제 정의

대학의 비교과 프로그램·공모전 소식은 학교 홈페이지, 사업단 홈페이지, 대학 공식 인스타그램, 사업단 인스타그램 등 여러 채널에 나뉘어 올라온다. 마감일은 공지 본문이나 포스터 이미지 안에 있어 직접 읽어야 하고, 확인한 일정은 다시 손으로 캘린더에 옮겨야 한다. 그래서 신청 기간을 놓치는 일이 생긴다.

## 3. 동작 방식

```
[채널 목록] → ① 매일 1회 자동 수집 → ② AI 정리 → ③ 공지 체크 화면 → ④ 구글 캘린더 등록
               (인스타그램 공식 API,    (공지 판별, 행사명·신청기간·   (원문 링크와    (체크한 공지만)
                홈페이지 메인 공지 칸)    마감일·대상·신청방법 추출)     함께 확인)
```

새 공지가 생기면 이메일로 알림을 보낸다.

## 4. 사용 방법

> 🚧 개발 중입니다. 각 방식은 단계별로 공개됩니다.

### 방법 A. 프롬프트 방식 (설치 없음)
공지 링크나 캡처를 AI에 붙여넣고 [`prompts/`](prompts/)의 프롬프트를 사용한다. — *2단계(~11/06) 공개 예정*

### 방법 B. 에이전트 방식
레포를 fork한 뒤 Claude Code 같은 AI 에이전트에게 "이 레포 안내대로 설치해 줘"라고 요청한다. API 키 입력과 구글 계정 연결처럼 개인 정보가 필요한 단계는 직접 진행한다. — *4단계 공개 예정*

### 방법 C. 직접 설치
설치·실행 순서는 개발이 진행되며 추가한다.

## 5. 우리 학교에 맞게 바꾸기

[`config/channels.yaml`](config/channels.yaml)의 인스타그램 계정과 홈페이지 주소만 바꾸면 다른 학교에서도 쓸 수 있도록 만든다.

## 6. 수집 원칙

- 홈페이지는 `robots.txt`와 이용약관을 확인하고 **허용된 범위에서만** 수집한다. 확인 결과는 [`docs/collection-policy.md`](docs/collection-policy.md)에 기록한다.
- 인스타그램은 **공식 Instagram API**(Business Discovery)로만 수집한다.
- 자동 수집은 **하루 1회**로 제한한다.
- 게시물 속 개인 연락처 등 개인정보는 저장하지 않으며, 원문 전체가 아닌 **정리한 정보와 원문 링크만** 보관한다.
- AI가 정리한 결과는 항상 원문 링크와 함께 보여 주어 사용자가 직접 대조할 수 있게 한다.

## 7. 기술 스택

| 구분 | 내용 |
|---|---|
| 언어 | Python |
| AI | Gemini API (공지 판별·정보 추출) |
| 수집 | Requests, Beautiful Soup, Instagram Graph API |
| 화면 | Streamlit |
| 캘린더 | Google API Python Client |
| 자동 실행 | GitHub Actions |

사용 오픈소스와 라이선스는 [`docs/oss-license-check.md`](docs/oss-license-check.md)에 정리한다.

## 8. 폴더 구조

```text
MAGAMI/
├─ config/        채널 목록 (자기 학교로 바꿀 때 이 파일만 수정)
├─ prompts/       공지 판별·정리 프롬프트
├─ src/           소스코드
├─ tests/         테스트·정확도 평가
├─ data/          샘플 데이터, 정답 자료(ground_truth)
├─ docs/          계획서, 주간 기록, 수집 정책, 데이터 형식, 라이선스 점검
├─ reports/       결과보고서, 발표자료
└─ assets/        이미지 등
```

## 9. 목표 지표

- 실제 공지 30건 기준 **마감일 정리 정확도 90% 이상** — 정의는 [`docs/schema.md`](docs/schema.md)
- 팀 외부 학생 **5명이 레포 안내만으로** 자기 캘린더 자동화 구현
