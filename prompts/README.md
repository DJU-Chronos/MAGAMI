# prompts

공지 판별과 정보 정리에 쓰는 프롬프트를 보관합니다.

| 파일 | 용도 |
|---|---|
| [`extract_notice.md`](extract_notice.md) | 공통 추출 프롬프트: 공지인지 판별하고 행사명·신청 기간·마감일·대상·신청 방법을 JSON으로 정리 |

이 프롬프트 하나를 **세 경로가 함께** 씁니다.

- **프롬프트 방식**: 아래 사용법대로 AI 채팅에 붙여넣어 사용
- **크롬 확장 프로그램**: `extension/prompt.md`로 복사해 사용 (`python scripts/sync_prompt.py`)
- **자동화**: `src/magami/extract.py`가 Gemini API 호출에 사용

프롬프트를 고치면 모든 경로의 결과가 함께 바뀝니다. 고친 뒤에는 정확도를 다시 측정합니다. 이때 프롬프트 개선에는 튜닝용 정답 자료만 씁니다 ([`docs/schema.md`](../docs/schema.md) 참고).

## 프롬프트 방식 사용법 (설치 없음)

인스타그램 게시물이나, 학교 홈페이지처럼 자동 수집하지 않는 공지를 정리할 때 씁니다.

1. [`extract_notice.md`](extract_notice.md)의 내용을 **전부 복사**합니다.
2. Gemini, ChatGPT, Claude 같은 AI 채팅 창에 붙여넣습니다.
3. 바로 아래에 공지 정보를 붙여넣습니다.

   ```
   ## 공지
   - 원문 링크: https://...
   - 게시일: 2026-11-20
   - 오늘 날짜: 2026-11-27
   - 본문:
   (공지 본문이나 인스타그램 캡션을 붙여넣기)
   ```

   포스터에만 날짜가 있으면 포스터 이미지나 화면 캡처를 함께 첨부합니다.
4. AI가 돌려준 JSON에서 `deadline`(마감일)을 **원문과 직접 대조**합니다.
5. 맞으면 구글 캘린더에 등록합니다.

> 개인 연락처가 들어간 공지는 붙여넣기 전에 연락처를 지워도 결과에는 영향이 없습니다.

### 결과 예시

```json
{
  "is_notice": true,
  "title": "2026 AI·OSS 프로젝트 동아리 모집",
  "apply_start": "2026-09-30",
  "apply_end": "2026-10-05",
  "deadline": "2026-10-05",
  "deadline_time": null,
  "target": "SW융합대학 재학생",
  "how_to_apply": "신청서 작성 후 이메일 제출"
}
```
