# 정답 자료

실제 공지를 사람이 직접 읽고 정리한 정답입니다. 형식은 [`docs/schema.md`](../../docs/schema.md)를 따릅니다.

| 폴더 | 용도 | 건수 |
|---|---|---|
| `eval/` | 최종 정확도 평가 전용, **프롬프트 개선에 사용 금지** | 30건 |
| `tuning/` | 프롬프트 개선용 | 10~20건 |

## 작성 규칙

- 공지 1건당 JSON 파일 1개, 파일 이름은 `id`와 같게 한다.
- 원문 링크(`url`)를 반드시 넣는다.
- 게시물 속 개인 연락처는 적지 않는다.
- 판단이 애매한 공지는 Issue에 남기고 팀원과 기준을 맞춘다.
- 신청 기간이 있는 공지뿐 아니라 **공지가 아닌 게시물(`is_notice: false`)도 일부 포함**해야 판별 정확도를 잴 수 있다.
